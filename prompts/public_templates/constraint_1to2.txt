生成的测试用例用于对一个类C语言的编译器进行测试。
1. 测试用例的程序结构必须以若干全局声明（常量或变量）开头，可跟若干函数定义，最后必须有且仅有一个主函数：int main() {{ ... return 0; }}。主函数末尾必须显式包含 "return 0;"，且返回值只能是字面量 0。
2. 所有标识符（变量名、常量名、函数名）必须先声明后使用；全局作用域内所有标识符（包括函数、变量、常量）不能重名；局部作用域内也不能有同名标识符；内层作用域可遮蔽外层同名标识符。
3. 常量（用 const 声明）必须在声明时初始化，且初值必须是常量表达式（即仅由整型字面量、已声明的常量、编译期可求值的算术表达式组成）；常量不能被赋值，也不能作为赋值语句左侧的左值。
4. 全局变量若未初始化，默认为 0；若初始化，初值必须是常量表达式。对于全局变量数组或常量数组，若初始化列表未提供全部元素，则其余元素默认初始化为 0。局部变量可不初始化（值未定义）；若初始化，初值可以是任意表达式。
5. 允许使用 static 修饰局部变量，但不能用于全局变量。static 局部变量未初始化时默认为 0，且仅初始化一次，其作用域仍限于所在函数。
6. 数组必须是一维的，长度必须是编译期可求值的非负整数常量表达式。数组访问必须带一个下标表达式（如 a[i]），不能多维、不能省略。
7. 函数可以是 int 或 void 类型。int 函数的函数体内部的最后一行必须显式的给出一个有返回值的return语句，即使它不可达也要有。void 函数只能出现 "return;"，且可以没有return语句。return语句允许不可达。
8. 函数参数类型只能是 int 或 int[]。若形参是 int，实参必须是整型表达式（变量、常量、数组元素）；若形参是 int[]，实参必须是变量数组名（不能是常量数组，也不能是普通变量）。
9. 表达式支持算术（+ - * / %）、关系（== != < > <= >=）和逻辑运算（! && ||）。多个一元运算符（+、-、!）可以连续使用，但不能有两个相同的运算符直接相邻（如 --i、!!a 非法），且 ! 仅可用于条件表达式。关系与逻辑运算结果为 1（真）或 0（假），条件判断中非 0 为真，0 为假；运算符优先级、结合性及短路求值规则同 C 语言。
10. 语句包括赋值、表达式、语句块、if、for、break、continue、return、printf。其中：赋值语句左侧必须是可修改的变量（不能是常量）；break 和 continue 只能出现在 for 循环体中（直接或嵌套）；SysY 程序可调用两个运行时库函数：getint()（无参，返回 int）和 printf(StringConst, Exp, ...)。StringConst 为字符串常量，仅含 ASCII 字符（编码 32、33、35–126）及转义序列 \\n，格式符仅支持 %d，且 %d 数量必须与后续整型表达式参数数量一致。尽管字符串常量类型超出 SysY（仅支持 int 和 int[]），编译器须正确处理此类调用。这两个函数无需显式声明即可使用。词法上，标识符由字母、数字、下划线组成，不能以数字开头；保留字（如 int、const、if、for 等）不能用作标识符；注释语法与 C 语言一致。
11. 不支持自增（++）和自减（--）运算符，也不支持复合赋值运算符（+=，=，*=，/=，%=）。
12. 函数调用的参数类型和数量必须与函数声明时匹配。
13. 关系运算符（== != < > <= >=）和逻辑运算符（! && ||）【只能】出现在if、for 语句的判断条件中，不能出现在 赋值语句右侧、算术表达式、函数参数或return语句的返回值中。
二、错误程序的约束
错误程序用于测试学生编译器的错误识别能力，必须只包含以下明确定义的错误中的一种或多种，且错误形式必须严格符合其定义。
a 类错误：源程序中出现了单独的 & 或 |，应视为非法符号（正确应为 && 或 ||）。需要满足&& 或 ||的使用规范，只能出现在条件表达式中。
错误程序必须满足以下限制：
每一行最多只包含一个错误；
不会出现“恶意换行”（如在字符串、函数调用等结构中故意换行使错误难以定位）；
for 语句中不会出现错误，以避免语法歧义；
错误之外的部分应保证语法和语义正确，以确保错误可被准确识别；
不得包含除上述错误之外的任何错误（如非法转义、非法标识符、使用指针、while 等不支持的特性）。
