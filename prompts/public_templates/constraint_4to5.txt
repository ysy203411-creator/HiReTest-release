The generated test cases are used to test a class C language compiler.
1. The program structure of the test case must start with several global declarations (constants or variables), followed by several function definitions, and end with exactly one main function: int main() {{ ... return 0; }}. The main function must explicitly include return 0; at its end, and the return value can only be the literal 0.
2. All identifiers (variable names, constant names, function names) must be declared before they are used; all identifiers in the global scope (including functions, variables, and constants) must not be duplicated; there must also be no duplicate identifiers in the local scope; inner scopes can shadow outer scope identifiers with the same name.
3. Constants (declared with const) must be initialized at the time of declaration, and the initial value must be a constant expression (i.e., composed solely of integer literals, previously declared constants, and arithmetic expressions that can be evaluated at compile time); constants cannot be assigned, and cannot appear as the left-hand side of an assignment statement.
4. If a global variable is not initialized, it defaults to 0; if it is initialized, the initial value must be a constant expression. For global arrays or constant arrays, if the initialization list does not provide all elements, the remaining elements are default-initialized to 0. Local variables may not be initialized (their values are undefined); if initialized, the initial value can be any expression.
5. The use of static to modify local variables is allowed, but not for global variables. A static local variable that is not initialized defaults to 0 and is initialized only once; its scope remains limited to the function in which it is defined.
6. Arrays must be one-dimensional, and their length must be a non-negative integer constant expression that can be evaluated at compile time. Array access must include an index expression (e.g., a[i]), and cannot be multidimensional or omitted.
7. Functions can be of type int or void. For an int function, the last line of the function body must explicitly be return exp; even if it is unreachable. A void function can only contain return; (without an expression), and may not contain a return statement. Any number of return statements can appear at any position in a function, and they may be unreachable.
8. The types of function parameters can only be int or int[]. If the formal parameter is int, the actual argument must be an integer expression (variable, constant, or array element); if the formal parameter is int[], the actual argument must be a variable array name (not a constant array, nor a regular variable).
9. Expressions support arithmetic operators (+, -, *, /, %). Multiple unary operators (+, -, !) can be used consecutively, but two identical operators cannot be adjacent (e.g., --i is invalid).
10. SysY programs can call two runtime library functions: getint() (no parameters, returns int) and printf(StringConst, Exp, ...). StringConst is a string constant, containing only ASCII characters (codes 32, 33, 35–126) and the escape sequence \\n; the format specifier only supports %d, and the number of %d must match the number of subsequent integer expression parameters. Although the string constant type exceeds SysY (only int and int[] are supported), the compiler must correctly handle such calls. These two functions can be used without explicit declaration. Lexically, identifiers consist of letters, digits, and underscores, and cannot start with a digit; reserved words (such as int, const, if, for, etc.) cannot be used as identifiers; the comment syntax is consistent with C language.
11. The test case is only allowed to contain the following statements; all other statement types not mentioned are prohibited: constant declaration; variable declaration; input and assignment statements; expressions involving addition, subtraction, multiplication, division, and modulo operations; function definitions and calls; array operations; output statements.
12. The increment (++), decrement (--), and compound assignment operators (+=, =, *=, /=, %=) are not supported.
13. The types and number of parameters in a function call must match those declared in the function.
