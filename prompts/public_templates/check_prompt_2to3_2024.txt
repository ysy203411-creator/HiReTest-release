#测试用例约束
生成的测试用例用于对一个类C语言的编译器进行测试。
1. 测试用例的程序结构必须以若干全局声明（常量或变量）开头，可跟若干函数定义，最后必须有且仅有一个主函数：int main() {{ ... return 0; }}。主函数末尾必须显式包含 return 0;，且返回值只能是字面量 0。
2. 所有标识符（变量名、常量名、函数名）必须先声明后使用；全局作用域内所有标识符（包括函数、变量、常量）不能重名；局部作用域内也不能有同名标识符；内层作用域可遮蔽外层同名标识符。
3. 变量和常量只允许出现 int 和char 两种类型以及这两种数据类型的一维数组类型。常量（用 const 声明）必须在声明时初始化，且初值必须是常量表达式（即仅由整型字面量、已声明的常量、编译期可求值的算术表达式组成）；常量不能被赋值，也不能作为赋值语句左侧的左值。
4. 全局变量若未初始化，默认为 0；若初始化，初值必须是常量表达式。对于全局变量数组或常量数组，若初始化列表未提供全部元素，则其余元素默认初始化为 0。局部变量可不初始化（值未定义）；若初始化，初值可以是任意表达式。
5. 数组必须是一维的，长度必须是编译期可求值的非负整数常量表达式。数组访问必须带一个下标表达式（如 a[i]），不能多维、不能省略。
6. 函数可以是 int ，char 或 void 类型。有返回值函数必须在最后一行有 return exp;语句。
7. 函数参数类型只能是 int，char,以及对应的数组类型int[]，char[]。若形参是数组或字符串，实参必须是变量数组名（不能是常量数组，也不能是普通变量）。
8. 表达式支持算术（+ - * / %）、关系（== != < > <= >=）和逻辑运算（! && ||）。多个一元运算符（+、-、!）可以连续使用，但不能有两个相同的运算符直接相邻（如 --i、!!a 非法），且 ! 仅可用于条件表达式。关系与逻辑运算只能出现在条件判断中，不可以用于赋值和运算语句。运算符优先级、结合性及短路求值规则同 C 语言。
9. 语句包括赋值、表达式、语句块、if、for、break、continue、return、printf。其中：赋值语句左侧必须是可修改的变量（不能是常量）；break 和 continue 只能出现在 for 循环体中（直接或嵌套）；SysY 程序可调用三个运行时库函数(这三个函数无需显式声明即可使用）：getint()（无参，返回 int），getchar()（无参，返回char）和 printf(StringConst, Exp, ...)。StringConst是字符串常量，包括 32-126 的所有 ascii字符，格式符仅支持 %d和%c，其他 C 语言中的格式字符，如 %f 都视为普通字符； printf的字符串常量中转义字符中只会出现 '\n'，反斜杠只会与 n 一起出现作为一个整体表示换行。
10. 词法上，标识符由字母、数字、下划线组成，不能以数字开头；保留字（如 int、const、if、for 等）不能用作标识符；注释语法与 C 语言一致；整型常量为非负十进制整数（负号属于一元运算符，不是常量的一部分）。
11. 不支持自增（++）和自减（--）运算符，也不支持复合赋值运算符（+=，=，*=，/=，%=）。
##特殊情况
允许出现以下错误，必须只包含以下明确定义的错误中的一种或多种，且错误形式必须严格符合其定义。出现以下错误时若满足限制，则仍算作【满足约束】。
a 类错误：源程序中出现了单独的 & 或 |，应视为非法符号（正确应为 && 或 ||）。& 或 |仍要遵循&& 或 ||的规则，只能出现在条件表达式中
i 类错误：缺少语句或声明结尾的分号 ;。
j 类错误：缺少右小括号 )，出现在函数定义、函数调用、if/for 条件或括号表达式中。
k 类错误：缺少右中括号 ]，出现在数组定义或数组访问中。
错误程序必须满足以下限制：
每一行最多只包含一个错误；
不会出现“恶意换行”（如在字符串、函数调用等结构中故意换行等不符合正常代码编写中会出现的情况）；
for 语句中不会出现错误，以避免语法歧义；
错误之外的部分应保证语法和语义正确，以确保错误可被准确识别；
不得包含除上述错误之外的任何错误（如非法转义、非法标识符、使用指针、while 等不支持的特性）。
