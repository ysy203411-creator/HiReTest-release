# Test Case Constraints
The generated test case is used to test a C-like language compiler.
1. The program structure of the test case must start with several global declarations (constants or variables), followed by several function definitions, and end with exactly one main function: int main() {{ ... return 0; }}. The main function must explicitly include return 0; at the end, and the return value can only be the literal 0.
2. All identifiers (variable names, constant names, function names) must be declared before they are used; all identifiers in the global scope (including functions, variables, and constants) must not be duplicated; there must be no duplicate identifiers in the local scope; inner scopes can shadow outer scope identifiers with the same name.
3. Variables and constants can only appear in int and char types, and their one-dimensional array types. Constants (declared with const) must be initialized at declaration, and the initial value must be a constant expression (i.e., composed only of integer literals, declared constants, and arithmetic expressions that can be evaluated at compile time). Constants cannot be assigned, and cannot appear as the left-hand side of an assignment statement.
4. Global variables that are not initialized default to 0; if initialized, the initial value must be a constant expression. For global variable arrays or constant arrays, if the initialization list does not provide all elements, the remaining elements default to 0. Local variables may not be initialized (value is undefined); if initialized, the initial value can be any expression.
5. Arrays must be one-dimensional, and the length must be a non-negative integer constant expression that can be evaluated at compile time. Array access must include an index expression (e.g., a[i]), and cannot be multidimensional or omitted.
6. Functions can be of type int, char, or void. Functions with return values must have a return exp; statement on the last line.
7. Function parameter types can only be int, char, and their corresponding array types int[] and char[]. If the formal parameter is an array or string, the actual argument must be a variable array name (not a constant array, nor a regular variable).
8. Expressions support arithmetic (+ - * / %), relational (== != < > <= >=), and logical (! && ||) operations. Multiple unary operators (+, -, !) can be used consecutively, but cannot have two identical operators adjacent (e.g., --i, !!a are invalid). ! can only be used in conditional expressions. Relational and logical operations can only appear in conditional judgments and cannot be used in assignments or arithmetic statements. Operator precedence, associativity, and short-circuit evaluation rules are the same as in C.
9. Statements include assignment, expression, statement block, if, for, break, continue, return, and printf. Among these: the left-hand side of an assignment statement must be a modifiable variable (not a constant); break and continue can only appear in for loops (directly or nested); SysY programs can call three runtime library functions (these three functions do not need to be explicitly declared and can be used directly): getint() (no parameters, returns int), getchar() (no parameters, returns char), and printf(StringConst, Exp, ...). StringConst is a string constant, including all ASCII characters from 32 to 126; format specifiers only support %d and %c; other C language format specifiers, such as %f, are treated as ordinary characters; in the string constant of printf, the only escape character that can appear is '\n', and the backslash will only appear with n together as a whole to represent a newline.
10. Lexically, identifiers consist of letters, digits, and underscores, and cannot start with a digit; reserved words (such as int, const, if, for, etc.) cannot be used as identifiers; the comment syntax is consistent with C; integer constants are non-negative decimal integers (the minus sign is a unary operator and not part of the constant).
11. The ++ and -- operators are not supported, nor are compound assignment operators (+=, =, *=, /=, %=).
